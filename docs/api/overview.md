# API overview

The REST API uses JSON and the `/api/v1` prefix. Current routes and access levels are listed in the root [README](../../README.md#implemented-api-routes). Authenticated requests use `Authorization: Bearer <token>`.

Controllers validate request DTOs and return response DTOs. Assessment question responses omit answer keys; the server evaluates submitted options. User-owned records are addressed through the authenticated principal rather than a caller-supplied user ID.

OpenAPI is generated by Springdoc. The interactive Swagger UI is available at `/swagger-ui.html` and the JSON contract at `/v3/api-docs`. Protected operations declare the `bearerAuth` HTTP bearer scheme; registration, login, and public grammar reads remain public in the contract. Set `SPRINGDOC_API_DOCS_ENABLED=false` and `SPRINGDOC_SWAGGER_UI_ENABLED=false` to disable the documentation endpoints.

Errors use RFC 9457 Problem Details (`application/problem+json`) with the standard `type`, `title`, `status`, `detail`, and `instance` fields plus a stable Polyglot `code` extension. Validation errors use `VALIDATION_ERROR`; authentication and authorization failures use `AUTHENTICATION_REQUIRED` and `ACCESS_DENIED`.
